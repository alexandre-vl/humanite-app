| 0001 Monorepo pnpm | pnpm 11.26.0 avec `nodeLinker: isolated`, `strictDepBuilds`, `minimumReleaseAge: 1440` explicite (strict), `pmOnFail: error`, `verifyDepsBeforeRun: error` fonctionnent avec Expo SDK 57 ; `enableGlobalVirtualStore: false` épinglé, car sa valeur par défaut change avec `CI` et `verifyDepsBeforeRun` échoue alors ; `allowBuilds` liste chaque script d'installation (`unrs-resolver: false`) ; le catalog épingle des versions de plus de 24 h ; `pnpm add` en `catalogMode: strict` écrit des plages dans le catalog → `deps:check` impose versions exactes et égalité avec `bundledNativeModules.json` ; la racine est un dépôt git avant toute génération | 3, 2c, 8, 13 |
| 0002 Plateforme Expo SDK 57 | template `default@sdk-57` sans web ; React Compiler `panicThreshold: 'all_errors'` inconditionnel (le preset lit `caller.isDev`) ; mutation de props non détectée → props `Readonly` ; `android.predictiveBackGestureEnabled: false` tant que RN n'enregistre son callback retour que sur les appareils API 36, avec le parcours `system-back` sur Android 15 comme garde ; le `.gitignore` du template exclut `/android` et `/ios` (dossiers générés), et `expo prebuild` les recrée par défaut → `--no-clean` réservé aux itérations locales de configuration ; un crash natif (`MountingCoordinator::pullTransaction`) vu une fois puis 0 sur 30 démarrages → à surveiller sur build release | 3, 10, 12, 19, 20 |

| 0004 Lint et format | configuration ESLint 10 validée sur fichiers fautifs ; `noInlineConfig` + `--max-warnings 0` + `no-warning-comments` ; doublons react-x désactivés ; une politique boundaries mal formée est ignorée sans erreur → tests des garde-fous obligatoires ; `no-restricted-properties` reprend la liste **mesurée** des APIs absentes de Hermes, pas la documentation | 8, 15 |

| 0009 Émulateur Android | Redroid 15 (`15.0.0_64only`, digest épinglé + tag local) démarre en 15 s, 0,9–1,3 Gio avec l'app, WebView 128 ; garde root et instantané restaurent l'hôte (14 `OK` après boot, après arrêt et après recréation) ; le contrôle sans root ne voit ni 12 des 21 sysctls ni les instances tracefs laissées par Android (`bootreceiver`) → le garde root reste obligatoire, y compris une fois après l'arrêt du conteneur ; séquence `emulator:up` : binder → conteneur → `boot_completed` → `adb root` → lmkd en seuils `minfree` + `lmkd.reinit` → `adb reverse tcp:8081 tcp:8081` → lien profond du dev client avec `disableOnboarding=1&disableAutoLaunch=1&disableFab=1` ; Metro sans `CI`, en IPv4 ; build natif par service utilisateur plafonné à 6 Gio, en créneau calme, CPU bornée par `taskset` : 12 min propre, 3,5 min incrémental, jamais tué ; Maestro 2.10 (4 parcours verts) et scrcpy 4.1 (enregistrement) fonctionnent. **Limites** : aucun décodage vidéo (gralloc sans `lockYCbCr`), aucune mesure de performance, Android 16 non couvert, visualisation depuis le laptop non testée | 2, 2b, 11, 12, 13, 14, 17, 18, 21 |
